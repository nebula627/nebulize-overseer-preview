# Slash command reference

Commands registered by the current private build. Availability depends on configured role grants, channel restrictions and Discord permissions. Custom configured slash commands supplement this list.

| Command | Function |
| --- | --- |
| `/community help` | List the community features |
| `/community stats` | View recorded message and voice activity |
| `/community leaderboard` | View the top ten members by message count |
| `/community poll` | Create a single-choice poll; separate options with / |
| `/community poll-results` | Show current poll totals |
| `/community poll-close` | End your poll or any poll you can moderate |
| `/community role-menu` | Publish buttons for up to five safe self-service roles |
| `/community ddns` | Show the existing DDNS status without changing DNS |
| `/moderation warn` | Record a warning for a member |
| `/moderation warnings` | Read a member’s last ten warnings |
| `/moderation timeout` | Timeout a member; zero minutes removes the timeout |
| `/moderation kick` | Kick a member from this server |
| `/moderation ban` | Ban a member without deleting message history |
| `/moderation purge` | Delete up to 100 recent messages in this channel |
| `/community-settings channels` | Set welcome and moderation log channels |
| `/community-settings autorole` | Set or disable the role assigned to new members |
| `/community-settings automod` | Enable spam deletion and optional blocked words separated with / |
| `/community-settings response` | Add an exact-message auto response; omit response to remove it |
| `/overseer help` | Show command groups and access levels |
| `/overseer status` | Show bot connection status |
| `/overseer member-info` | View join date and account creation date |
| `/community rank` | View your XP and level or another member’s |
| `/community levels` | View the XP leaderboard |
| `/community servers` | View game server status from the linked uptime page |
| `/moderation untimeout` | Remove a member’s timeout |
| `/moderation unban` | Unban a Discord user by ID |
| `/moderation role-change` | Add or remove an ordinary role from a member |
| `/community-settings access` | Owner configures helper, moderator, or full-control Discord roles |
| `/community-settings view` | View current bot configuration |
| `/community afk` | Set an AFK notice until your next message |
| `/community tag` | Show a configured community tag |
| `/community remind` | Schedule a reminder in this channel |
| `/community giveaway` | Create a giveaway with persistent entry buttons |
| `/community balance` | View private-server coins and community points |
| `/community daily` | Claim your daily private-server coin reward |
| `/community custom` | Run a configured custom reply |
| `/moderation points` | Add or remove community points for a member |
| `/moderation slowmode` | Set this channel’s Discord slowmode |
| `/community choose` | Pick one option separated with / |
| `/community roll` | Roll a die |
| `/community birthday` | Opt in to birthday announcements using month and day only |
| `/community birthday-remove` | Remove your saved birthday and opt out of announcements |
| `/community achievements` | View your community activity achievements |
| `/community invites` | View your tracked invite counts |
| `/overseer room-name` | Rename your currently joined temporary voice room |
| `/community shop` | List private coin-shop roles or buy a named item |
| `/overseer pay` | Transfer private coins to another server member |
